# Prigo Enterprises

Prigo Energy & Smart Home Solutions — Next-Generation Web Platform.

## Features
- **Solar Solutions**: Rooftop systems, inverters, solar panels, and batteries.
- **RO & Water Systems**: High-efficiency water purification and filtration.
- **Electrical & Home Appliances**: Smart ACs, refrigerators, washing machines, and air coolers.
- **Professional Services**: Installation, maintenance, AMC, and on-demand repair.

## Tech Stack
- Next.js 16 (App Router)
- React 19
- Tailwind CSS
- Lucide Icons
